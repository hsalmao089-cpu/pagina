import anthropic

client = anthropic.Anthropic(
    api_key="SUA_CHAVE",
    base_url="https://api.seudominio.com.br",
)

resposta = client.messages.create(
    model="claude-opus-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "Olá, Claude!"}],
)

for bloco in resposta.content:
    if bloco.type == "text":
        print(bloco.text)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "SUA_CHAVE",
  baseURL: "https://api.seudominio.com.br",
});

const resposta = await client.messages.create({
  model: "claude-opus-5",
  max_tokens: 16000,
  messages: [{ role: "user", content: "Olá, Claude!" }],
});

for (const bloco of resposta.content) {
  if (bloco.type === "text") console.log(bloco.text);
}

Dúvidas

Perguntas frequentes

A open33 é a Anthropic?

Não. A open33 é um serviço independente que oferece acesso ao Claude Opus 5 por meio de uma API compatível. Não somos afiliados, patrocinados nem endossados pela Anthropic. Claude é uma marca da Anthropic.

Preciso mudar meu código?

Quase nada. Se você usa os SDKs oficiais ou chama a API de Messages por HTTP, basta trocar a base URL e a chave. Se preferir, defina as variáveis ANTHROPIC_BASE_URL e ANTHROPIC_API_KEY e não mude nenhuma linha.

Qual modelo está disponível?

O Claude Opus 5, em todos os planos. Nas requisições, use claude-opus-5 no campo model.

Como funciona a cobrança?

É um plano mensal com valor fixo em reais. Você paga com Pix ou cartão de crédito nacional, e a assinatura renova todo mês.

Tem garantia?

Sim. Você tem 7 dias para testar: se a open33 não for pra você, é só pedir o reembolso integral nesse prazo.

Existe limite de uso?

Sim. Cada plano tem limites de requisições e de tokens, informados no painel. Se o seu projeto precisar de mais, você pode mudar de plano ou falar com a gente sobre um plano sob medida.

O que acontece se eu atingir o limite do plano?

As requisições acima do limite são recusadas temporariamente, com o mesmo erro 429 da API, até a janela seguinte. Se isso acontecer com frequência, vale mudar para um plano maior.
