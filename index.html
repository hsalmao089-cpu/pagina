import anthropic

client = anthropic.Anthropic(
    api_key="SUA_CHAVE",
    base_url="https://api.seudominio.com.br",
)

resposta = client.messages.create(
    model="claude-opus-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "Olá, Claude!"}],
)

for bloco in resposta.content:
    if bloco.type == "text":
        print(bloco.text)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "SUA_CHAVE",
  baseURL: "https://api.seudominio.com.br",
});

const resposta = await client.messages.create({
  model: "claude-opus-5",
  max_tokens: 16000,
  messages: [{ role: "user", content: "Olá, Claude!" }],
});

for (const bloco of resposta.content) {
  if (bloco.type === "text") console.log(bloco.text);
}

Dúvidas

Perguntas frequentes

A Órbita é a Anthropic?

Não. A Órbita é um serviço independente que oferece acesso aos modelos Claude por meio de uma API compatível. Não somos afiliados, patrocinados nem endossados pela Anthropic. Claude é uma marca da Anthropic.

Preciso mudar meu código?

Quase nada. Se você usa os SDKs oficiais ou chama a API de Messages por HTTP, basta trocar a base URL e a chave. Se preferir, defina as variáveis ANTHROPIC_BASE_URL e ANTHROPIC_API_KEY e não mude nenhuma linha.

Existe limite de requisições?

Sim. Cada plano tem limites de requisições e de tokens por minuto, informados no painel. Se o seu projeto precisar de mais capacidade, fale com a gente sobre limites dedicados.

Como funciona a cobrança?

Você recarrega créditos em reais. Cada chamada desconta do saldo de acordo com os tokens de entrada e de saída e o preço do modelo usado, que fica visível no painel. Não há mensalidade nem cobrança automática.

Quais formas de pagamento vocês aceitam?

Pix e cartão de crédito nacional. Para empresas, também oferecemos faturamento mensal com nota fiscal.

O que acontece quando os créditos acabam?

As chamadas deixam de ser atendidas até a próxima recarga, e nada é cobrado sem o seu pedido. Você pode recarregar a qualquer momento pelo painel.
