# Os SDKs oficiais de Python e TypeScript também
# leem essas duas variáveis automaticamente.
import anthropic

client = anthropic.Anthropic(
    api_key="SUA_CHAVE",
    base_url="https://api.open33.tech",
)

resposta = client.messages.create(
    model="claude-opus-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "Olá, Claude!"}],
)

for bloco in resposta.content:
    if bloco.type == "text":
        print(bloco.text)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: "SUA_CHAVE",
  baseURL: "https://api.open33.tech",
});

const resposta = await client.messages.create({
  model: "claude-opus-5",
  max_tokens: 16000,
  messages: [{ role: "user", content: "Olá, Claude!" }],
});

for (const bloco of resposta.content) {
  if (bloco.type === "text") console.log(bloco.text);
}

Dúvidas

Perguntas frequentes

A open33 é a Anthropic?

Não. Somos um serviço independente que dá acesso ao Claude Opus 5 por uma API compatível. Não somos afiliados à Anthropic. Claude é uma marca da Anthropic.

Funciona no Claude Code, no Cursor e no Antigravity?

No Claude Code, defina ANTHROPIC_BASE_URL e ANTHROPIC_API_KEY com o endereço e a chave da open33. Nas outras ferramentas, use a opção de API ou endpoint personalizado com os mesmos dados.

Preciso mudar meu código?

Não. Com os SDKs oficiais ou chamadas HTTP, troque só a base URL e a chave.

Como funciona a cobrança e a garantia?

Plano mensal com valor fixo em reais, no Pix ou no cartão. Se não gostar, peça o reembolso integral em até 7 dias.

Existe limite de uso?

Sim. Cada plano tem limites de requisições e de tokens, informados no painel. Acima do limite, a API responde com erro 429 até a janela seguinte. Se isso for frequente, é hora de subir de plano.
